Types API Reference

This page documents the core data types in Relevent.jl.

Interaction History

InteractionHistory

Relevent.InteractionHistory — Type
InteractionHistory{T}

Track detailed interaction history for advanced REM statistics.

Fields

  • events::Vector{Event{T}}: All observed events
  • sender_history::Dict{Int, Vector{Int}}: Actor -> list of receivers (ordered by time)
  • receiver_history::Dict{Int, Vector{Int}}: Actor -> list of senders (ordered by time)
  • pair_history::Dict{Tuple{Int,Int}, Vector{T}}: (sender, receiver) -> list of event times
  • event_counts::Dict{Tuple{Int,Int}, Int}: Count of events per dyad

Model Types

OrdinalBPM

Relevent.OrdinalBPM — Type
OrdinalBPM

Ordinal relational event model: only the order of events is used. Each event contributes a multinomial-logit term over the full risk set,

P(event m is (s, r)) = exp(θ'x_sr) / Σ_{(i,j)} exp(θ'x_ij),

the ordinal likelihood of relevent::rem.dyad (no case-control sampling — compare REM.fit_rem, which samples the risk set).

source

OrdinalBPMResult

Relevent.OrdinalBPMResult — Type
OrdinalBPMResult

Results from fitting an ordinal BPM: exact maximum-likelihood coefficients over the full risk set, with observed-information standard errors.

source

TimingModel

Relevent.TimingModel — Type
TimingModel

Proportional-hazards model for inter-event times: dyad (i,j) has hazard λ_ij(t) = h₀(t)·exp(θ'x_ij) with baseline h₀ one of :exponential, :weibull, or :gompertz. Only the exponential baseline has a fitted likelihood (see fit_timing); the others are available for hazard/survival evaluation.

source

TimingModelResult

Relevent.TimingModelResult — Type
TimingModelResult

Results from fitting a timing model. baseline_params[1] is the fitted baseline rate λ₀; coefficients are proportional-hazard log-rate effects.
